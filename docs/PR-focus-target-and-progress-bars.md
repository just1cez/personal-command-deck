# 聚焦「本轮目标」下拉选目标 + 手动改时长，推进界面待办 / 项目拖拽进度条

## 背景

延续「聚焦 / 推进」两个界面的日常打磨，这次补齐两个反复出现的诉求：

1. 聚焦页「本轮目标」以前只吃系统自动推荐，想专门盯某个待办或某个项目时没法直接指定；同时该页时长仍只能靠 ±5 分钟按钮调整。
2. 推进页每个条目只有「完成 / 未完成」这一个二元状态，像项目、需要多步推进的待办，缺一个「做到几成」的直观刻度。

沿用上一版思路：**新增能力全部通过可选字段注入，既有代码路径与本地存档保持兼容**。

## 改动内容

### 1. 聚焦「本轮目标」可下拉选目标 + 手动改时长

- 「本轮目标」标题右侧新增下拉（复用 `ThemedSelect`），可选：`自动推荐`（保留原自动推荐逻辑）、今日未完成的 Top 3 / 普通待办、进行中的项目。
- 选中「待办」后开始专注：时长同时记入该待办与默认项目，今日面板对应任务行会亮起「N 分」徽章；选中「项目」则记入该项目。运行中时下拉隐藏，避免与「正在专注」的目标产生歧义。
- 时长步进器中间的数字改为可直接键入的输入框（如 37），失焦 / 回车收敛到 5–120 分钟；±5 分钟按钮保留，运行中禁用编辑，与既有行为一致。
- 修复下拉展开时菜单宽度受「上次选中项」影响、长项被截断的问题：菜单改为按自身内容自适应（带上限），并从右边缘向面板内侧展开。

### 2. 推进界面待办 / 项目的可拖拽进度条（10% 步进）

- 今日面板的 Top 3、普通待办，以及项目推进中每个进行中的项目，新增可拖拽进度条（`<input type="range">`，步进 10%），直观表示完成度。
- 待办进度与完成状态联动：拖到 100% 自动勾选完成，从 100% 往下拖取消完成；勾选 / 取消勾选也会把进度同步为 100% / 0%，避免「已勾选但进度条不满」的矛盾态。
- 项目进度独立于「结项」生命周期，纯粹表示完成度，不影响结项 / 恢复流程。

## 技术要点

- 数据模型新增可选字段：`Task.progress?`、`Project.progress?`（`src/types.ts`），旧对象天然兼容。
- 归一化兜底集中在 `src/dashboardState.tsx`：`normalizeTasks` 缺省时按 `done` 推导（完成→100，否则→0），`normalizeProjects` 缺省 0；`src/utils.ts` 新增 `clampProgress`，把取值钳制到 0–100 并对齐 10% 网格，本地加载与备份导入两条路径共用。
- 完成度与完成态的联动只集中在两个写入口（`toggleTask` 勾选联动、`setTaskProgress` 拖拽联动），保持「100% ⇔ done」的单一语义；顶部「完成条」等既有按 `done` 的统计不变。
- 聚焦目标选择：`startFocus` 扩展可选 `taskId` 参数（默认 `''`，与旧调用点等价），模块级 `resolveManualFocusTarget` 把下拉选择解析为 `label / source / projectId / taskId`；引用项被删除 / 完成时解析为空，自动回落到「自动推荐」。
- UI 复用既有组件与写法：下拉复用 `ThemedSelect`，进度条与徽章延续 `TaskRow` 的可选属性扩展（明日 / 收据面板不传即不渲染）；下拉菜单宽度问题以作用域样式修复，不影响其它下拉。

## 涉及文件

- `src/types.ts` —— `Task.progress?` / `Project.progress?`
- `src/utils.ts` —— `clampProgress`（钳制 + 对齐 10%）
- `src/dashboardState.tsx` —— 任务 / 项目进度归一化与兜底
- `src/components.tsx` —— `TaskRow` 进度条、`FocusControls` 时长可手动输入
- `src/App.tsx` —— 聚焦目标下拉、`resolveManualFocusTarget`、`startFocus` 扩展 `taskId`、进度写入口
- `src/App.css` —— 进度条、时长输入框、目标下拉与菜单宽度样式

## 测试与验证

- `npm run lint` 与 `npm run build` 均通过。
- 手动核对：
  - 聚焦页下拉可选自动 / 待办 / 项目；选待办后开始并暂停，待办与项目各自记入同一段时长，任务行显示「N 分」徽章；选项目则记入项目。
  - 时长可直接键入并收敛到 5–120，±5 按钮仍生效，运行中禁用编辑。
  - 下拉展开时菜单宽度不再随上次选择变化，长待办 / 项目名可完整显示。
  - 今日面板待办、项目推进项目均可拖拽进度条，步进 10%；待办拖到 100% 自动完成、回拖取消；勾选框与进度条状态一致。
- 兼容性：载入不含 `progress` 的旧本地存档，字段自动补默认值（完成任务→100，其余→0，项目→0），无报错、界面正常。

## 兼容性 / 影响面

- 本地 `localStorage` 结构向后兼容，无需清数据或迁移；备份导入 / 导出随整体状态序列化，无需改动。
- 既有专注 / 项目统计、任务勾选 / 删除 / 排序 / 就地编辑、明日与收据面板、其它下拉框等均无回归。
